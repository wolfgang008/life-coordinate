## 评审建议路径

1. 打开[在线 Demo](https://life.wolfx.top)，选择“查看完整案例”快速体验完整闭环。
2. 观看演示视频，了解问题、产品流程和技术实现。
3. 阅读项目说明文档和路演 PPT，查看设计依据与核心亮点。
4. 如需本地验收，按项目 README 的“快速开始”运行，并执行 `npm test` 与 `npm run build`。
