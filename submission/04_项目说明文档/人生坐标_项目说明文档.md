## 二、项目简介

人生坐标是一款面向高中毕业生、大学生和毕业初期用户的 AI 学业与发展规划产品。它解决的核心问题是：用户知道许多专业与职业方向，却很难判断哪一条适合自己当下的能力、资源和现实条件。

产品不通过一次测评给出固定标签，而是把用户的学习经历、兴趣线索、家庭支持、所在城市、收入压力和可投入时间放进同一次分析。系统先生成可逐项确认的个人画像，再让多个模型独立提出规划，由决策模型综合比较，最后给出一项当周可以完成的小行动。用户完成行动并反馈后，系统更新下一版建议。

## 三、目标用户与应用场景

- 高中毕业生：专业选择、升学路径和假期探索。
- 在校大学生：转专业、辅修、实习和能力补强。
- 毕业初期用户：求职方向、城市选择和转型准备。
- 学校生涯教育与就业指导部门：降低重复初访成本，形成可追溯的学生探索记录。

## 四、核心功能

1. **分阶段访谈**：根据用户阶段展示不同问题，并收集地域、时间和收入等现实边界。
2. **可确认的 AI 画像**：把事实与模型推测分开，标明来源，允许用户接受、拒绝或纠正。
3. **多模型独立规划**：GPT、Claude 与 DeepSeek 基于同一份已确认画像分别提出完整路径。
4. **综合决策与个人地形册**：比较方向的理由、代价、风险和适用条件，保留主推与备选路线。
5. **第一行动**：把长期规划拆成当周可完成、可检查、可复盘的小任务。
6. **反馈闭环**：记录真实体验，更新画像和建议，避免一次建议长期固化。

## 六、Agent 工作流

1. 画像 Agent 读取结构化回答，生成事实、兴趣假设、能力线索、现实边界和关键未知。
2. 用户确认画像；未确认的推测不会直接限制规划结果。
3. 三个规划 Agent 独立工作，避免前一个模型的结论影响后续模型。
4. 输出校验层检查结构、来源、时间预算与现实边界。有效独立方案不足两份时，流程明确终止。
5. 决策 Agent 综合有效方案和已核验资料，形成主推方向、备选方向、条件路线与第一行动。
6. 用户反馈行动结果，系统更新画像版本并生成后续建议。

## 七、大模型使用说明

所有模型请求都由后端发起，前端不持有密钥。系统通过 OpenAI 兼容的 `POST /v1/chat/completions` 接口调用模型，并对超时、响应体积和 JSON 结构设置上限。

| 阶段 | 主模型 | 作用 |
| --- | --- | --- |
| 个人画像 | `gpt-5.4-mini` | 整理事实、假设、能力线索和关键未知 |
| 独立规划 A | `gpt-5.4-mini` | 提出一份完整路径，失败时使用 `gpt-5.4-nano` |
| 独立规划 B | `claude-sonnet-4-6` | 独立评估可行性与风险 |
| 独立规划 C | `deepseek-v4-flash` | 提供第三份独立方案，失败时使用 `deepseek-v4-pro` |
| 综合决策 | `gpt-5.4` | 比较有效方案并形成最终方向 |

模型输出必须经过业务协议校验。系统不会使用硬编码答案或本地规则伪造 AI 结果。

## 八、部署与运行

环境要求：Node.js 22.13 或更高版本、npm。浏览首页和完整案例不需要模型密钥。

```powershell
npm install
npm run db:local
npm run dev
```

打开 `http://127.0.0.1:8788`。运行真实分析时，在项目根目录创建不会纳入 Git 的 `.dev.vars`：

```dotenv
API_BASE="https://your-openai-compatible-endpoint.example/v1"
API_KEY="your-private-api-key"
```

## 十、数据与隐私

- 回答、规划和行动笔记默认保存在用户浏览器。
- 只有用户明确同意后，当次资料才会发往模型服务。
- 页面提醒用户不要填写姓名、联系方式、详细住址和资产信息。
- 服务端状态用于保持版本一致、隔离匿名会话和防止重复请求，过期数据会被清理。

## 十一、商业验证计划

当前 MVP 先验证个人用户能否完成“访谈、确认、行动、反馈”的完整闭环。下一阶段将记录首次背景整理用时、第一行动完成率和行动反馈后的继续使用率，判断产品是否能够降低学校生涯教育和就业指导中的重复初访工作，并提高规划后的实际行动率。
